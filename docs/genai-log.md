# GenAI log

AI use is required in this challenge, and the report has to end with a GenAI Disclosure: which parts AI wrote and which we wrote, where it helped with the text, 3 to 5 real prompts, and how we checked its output. That section is built from this log, so add a row on the day it happens.

- **Prompt:** copy the actual prompt, not a summary.
- **What we did with it:** kept, changed or rejected, and why. Note every time the AI was wrong (a hallucinated parameter, a metric that didn't match our run, code that didn't work): the disclosure has to show we caught those.
- Every number in the report comes from a run we executed, never from an AI answer.
